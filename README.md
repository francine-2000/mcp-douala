# mcp-douala

Petit serveur MCP en Python avec deux outils :

- `salut_douala(nom)` : salue la personne depuis Douala.
- `fcfa_en_euro(montant)` : convertit un montant en FCFA en euros (montant divisé par 656).

## Installation

```bash
pip install -r requirements.txt
```

## Lancement

```bash
python server.py
```
